# 📝 Advanced Todo List Web App

A modern and responsive Todo List application built using HTML, CSS, and JavaScript with local storage support.

---

## 🚀 Features

- ➕ Add new tasks
- ❌ Delete tasks
- ✏️ Edit tasks (double-click to edit)
- ✅ Mark tasks as completed (checkbox)
- 💾 Data saved using Local Storage (persists after refresh)
- ⌨️ Add tasks using Enter key
- 🎨 Beautiful responsive UI with animations

---

## 🛠️ Tech Stack

- HTML
- CSS (Glassmorphism + Animations)
- JavaScript (DOM Manipulation + LocalStorage)
